# 0.4.0 空间动态预览

- 默认采用蓝白空间页头、动态卡片与照片/相册网格。仍可切换至列表与详情。
- 时间线包含说说、照片、视频元数据及相册事件，取消原先前 100 条的展示限制。全部筛选结果进入列表模型；缩略图按实际绘制需求加载，并限制缓存。
- 支持年份、账号及搜索筛选；「查看全部」重置筛选并合并已添加账号。账号来源始终保留。进入相册时清除旧年份限制。
- 存档发现支持有限深度的嵌套目录，跳过媒体和构建缓存目录。不同账号相同记录编号不会互相覆盖。
- 点击动态图片直接预览，支持上一张、下一张和方向键。单条详情仍显示完整文字及本地图片。
- 归档结果区分下载/读取失败与暂不支持的视频；旧报告中的视频条目也按暂不支持展示。可按当前账号查看对应条目的文字、名称和原因。
- 后续媒体失败可记录脱敏的 HTTP 状态、超时或写入错误，不把带签名媒体地址放入报告。
- 应用内与离线 HTML 均支持已映射的 QQ 表情代码到系统 Emoji 的语义替代，原始内容保留。未确认的编号显示可读提示，避免误配情绪。

## 表情资源调研

[koishijs/QFace](https://github.com/koishijs/QFace) 收录腾讯原版表情；维护代码使用 MIT，但其 README 明确将腾讯资源版权与代码许可区分，并说明资源用途限制。QQNT 素材也不能保证对应所有历史空间表情。因此本版不将其素材打包进应用，使用系统 Unicode Emoji，不使用仿制表情图片。未知编号未声称已还原。

## 验证范围

使用合成数据验证超过 100 条的完整模型、末尾条目可达、多账号切换、年份筛选、查看全部、相册内照片、图片详情资源、表情与 HTML 转义。离线查看器脚本也验证混合时间线和账号切换。真实本地存档仅作只读兼容检查，不将其账号、内容、截图或条目统计写入公开材料。
