# 0.3.0 本地时光馆与多账号存档

应用顶部新增「连接与导出」「本地时光馆」。底部「打开本地存档」也进入时光馆，不再启动外部浏览器。时光馆通过只读 SQLite 连接打开已有存档；无需网络或登录，不修改原存档。

## 使用

- 导出时默认「分开保存」，每个账号单独文件夹；「合并保存」使用同一根目录下的「合并存档」，后续账号可继续导入。
- 时光馆自动识别当前根目录和其下一层账号文件夹。其他位置使用「添加已有存档」。已添加目录会记住；支持直接选择存档文件夹或包含多个账号的根文件夹。
- 账号框选择一个账号分开看，或选择「合并查看全部账号」。同名相册、相同照片/说说编号不会跨账号合并。相同账号重复导出的同条目优先选取含本地媒体的副本。
- 时间线同时展示说说和照片；另可切换相册、照片、说说。支持文字及日期搜索，点击条目看内容，进入相册浏览其照片，点击本地图片放大。
- 未下载图片显示缺失提示，文字和时间仍可阅读。视频仍只有元数据。已有独立存档的合并查看不会移动文件；选择合并保存不会自动迁移旧文件夹。

## 存储与兼容

数据库原有主键已包含账号，故合并保存无需修改数据库结构。每个账号的媒体路径仍保留账号号段。合并的离线 HTML 也包含账号筛选和来源；内容 ID 加入账号命名空间。命令行重新生成离线页会自动识别多账号数据库。单账号导出继续兼容原目录结构。

合并目录保留 `last-run.json` 作为最近一轮报告，同时保留 `last-run-<QQ号>.json`。分开导出的账号不会被自动迁移或删除。
