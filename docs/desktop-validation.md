# 扣扣时光桌面预览版 0.2.0

## 实现

- PySide6 / Qt Widgets 桌面窗口，独立 `qzonecapsule` 入口。
- 二维码在内存中显示；扫码状态、取消、重新扫码与本地退出登录。
- 勾选说说、相册、图片下载；读取相册列表后单独勾选。
- 备份目录按 QQ 号隔离，防止不同账号覆盖同一个离线入口。
- 共享同步服务，CLI 和桌面使用相同核心；QThread 后台任务通过信号更新界面。
- 中止保留已提交记录；原图候选失败后回退；失败/中断/停止与完成分别报告。
- 忽略非媒体错误页与空媒体响应，保留实际响应格式；EXIF 编辑后恢复文件时间。
- 保留空相册元数据；退出登录后仍可以选择已有离线存档。

## 自动验证

运行 `.venv/bin/pytest -q` 和 `.venv/bin/ruff check .`。

最终结果：39 项测试通过，Ruff 检查通过。

测试包括：模拟 HTTP 的二维码回调、换票、取消与异常域名拒绝；Qt 后台登录、读取列表、相册勾选、导出和退出；归档整合、原图降级、重复运行跳过文件、取消保存、源失败报告、账号隔离；媒体错误响应、空文件和格式保留。

Qt 测试使用 offscreen 平台，网络与归档界面流程使用模拟响应或临时测试数据。它们不证明 QQ 私有接口目前可用。

## 真实使用边界

macOS Apple Silicon 打包应用（含改名后的 QZoneCapsule.app）已实际启动，通过原生界面点击取得了腾讯返回的真实二维码，并验证取消登录后界面恢复可操作。`codesign --verify --deep --strict` 本地签名检查通过。

尚未使用手机确认真实账号登录，也未完成导出完整性验收。需要用户本人用手机确认扫码，再用小相册和少量说说核对文本、条目、图片和时间。

视频解析、完整评论/回复、字节级断点续传、仅重试失败任务的独立操作尚未实现。当前结果报告列出失败条目，重新导出重新扫描并补下载。

## 本机打包

先安装 `pip install -e '.[desktop]' 'pyinstaller>=6,<7'`，再运行 `packaging/build-macos.sh`。产物位于 `release/0.2.0/QZoneCapsule.app`；macOS 应用采用构建工具的本地签名，不是 Apple 开发者签名或公证。未构建 Windows/Linux 安装包。
