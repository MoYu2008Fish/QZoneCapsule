# 0.3.1 照片说明乱码修复

2026-10-25：本地存档确认部分相册照片说明已是 UTF-8 按 GBK/GB18030 错误解释后的文字；说说正文正常。乱码存在于数据库字段，不是 Qt 字体丢失。

本轮按用户选择修复本地显示，未重新登录或重新采集接口，也不修改空间设置。

- 查看器数据生成时识别这类编码痕迹；只在还原结果更可信时使用恢复文字。
- 对仍有缺字的说明，通过本地图片 SHA-256 与同账号说说配图比对；只有同一图片、文字匹配且来源唯一时，使用该说说原文校对恢复。
- 完整原始字段仍在 SQLite 中。显示层附恢复说明；不能恢复的字符显示 `�`，不声称文字完整。正常中文、英文、Emoji 保持原样。
- 应用内照片/相册内容和重新生成的离线页均使用相同处理。

本地验证覆盖通过图片和说说原文校对恢复，以及只能恢复部分文字并附缺字提示两类情况。公开记录不包含真实存档的条目统计。原数据库与图片不变。离线 HTML/data.js 更新前保留副本。

测试覆盖正常文字不变、可逆乱码恢复、缺字提示、同图来源校对、不同图片不匹配、多个来源不擅自替换、数据库原字段不改。网络端编码兼容尚未经过重新登录后的验证。
