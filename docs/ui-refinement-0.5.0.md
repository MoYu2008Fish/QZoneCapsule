# 0.5.0 · 参考图排版精修与 macOS 本机更新

本轮进一步对照根目录的 `QQ空间备份管理器界面.png`，将上轮普通双栏改为接近原图的错落布局：账号 / 内容统计占顶部，七类内容横排，右侧存储跨行，进度卡与并排渐变按钮对齐，任务表与年份图位于底部。默认 1544 × 900 窗口可完整显示总览；窄窗口保留单栏和顶部导航。

配色使用浅蓝底、近白渐变卡片、淡紫侧栏、蓝紫主按钮和七组彩色内容图标。未支持的导出类别继续明确标注；统计来自本地已加载的数据。任务表展示本次真实任务的范围、状态和结果，详细日志从「日志中心」展开。没有添加伪造的历史任务或远端空间统计。

## 图标

以 iOS 风格的蓝紫圆角方形、柔和高光、白色照片盒和叠放照片重绘应用图标，保持小尺寸下可辨识。原始可编辑文件为 `docs/images/icon.svg`；`packaging/build_icon.py` 生成 1024 PNG、各档位 iconset 和 macOS ICNS。页头、窗口图标和 macOS 应用包使用相同视觉。

## 打包与同步

- 版本：0.5.0，macOS arm64。
- 产物：`release/0.5.0/QZoneCapsule.app`、`QZoneCapsule-0.5.0-macos-arm64.zip`、`SHA256SUMS`。
- 打包脚本从源码读取版本，包含全部界面图标和离线模板，补齐 Finder 版本与显示名称，最后重新进行本地签名并生成压缩包。
- 已安装到 `/Applications/QZoneCapsule.app`，并同步现有发布目录内六个活动应用副本；保留原应用目录身份，以便原有 Finder 路径继续打开新版。
- 更新前旧应用备份位于 `release/replaced-before-0.5.0/`。本机同步清单位于构建目录，不作为公开素材。
- 使用本地临时签名，未进行 Apple 开发者签名或公证；远端版本状态以 GitHub Releases 页面为准。
