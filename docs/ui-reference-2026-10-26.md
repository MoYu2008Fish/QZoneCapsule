# 按根目录设计图重做桌面 UI

参考：根目录 `QQ空间备份管理器界面.png`。

主界面改为浅蓝紫顶部品牌区、左侧导航和双栏卡片总览。账号、内容统计、内容选择、格式与存储、导出进度、渐变操作按钮、日志和回忆年份分布对应设计图中的主要区域。新增本地矢量品牌图标、导航图标和照片盒插画，无外部素材请求。

原有扫码、退出登录、相册勾选、图片下载、保存位置、多个账号分开/合并导出、停止任务和本地时光馆入口继续使用原业务逻辑。图中的完整备份按钮替换为实际可用的本地时光馆入口；日志、留言、视频等尚未支持的导出类型明确标注，不提供无效格式选项或伪造远端账号统计。内容柱状图显示已加载的本地说说/照片数量；趋势图显示近七年本地内容日期分布，不宣称存在完整导出历史。记住的存档目录在启动后异步加载，切回总览时同步统计。

窗口宽度不足 1080 时隐藏侧栏、显示顶部导航菜单；总览内容宽度不足 940 时改为单栏，保留纵向滚动。窄窗口仍能在总览和时光馆之间往返。
