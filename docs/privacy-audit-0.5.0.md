# 0.5.0 发布前隐私检查

检查日期：2026-10-26。

当前分支和 0.5.0 发布材料已通过下述检查。另有一条不在分支/标签中的旧提交，GitHub 仍能按提交编号返回其非匿名邮箱；这项远端缓存残留尚未彻底清除。

## 范围与结果

- 检查当前源码、文档、图标、演示截图，以及远端主分支和公开版本标签对应的四次历史提交。
- Gitleaks 历史扫描未发现秘密；历史提交作者和提交者均使用公开项目署名与 GitHub noreply 邮箱。
- 对 Git 对象和当前文件另做已知真实账号、当前会话凭据、本机用户目录的精确检查；公开提交历史和本次待发布文件未命中这些内容。
- 本地旧的未引用 Git 提交中发现非匿名邮箱。已先在仓库外建立私有备份，再清理旧对象；复查活动对象数据库不再包含这项记录。进一步直接查询 GitHub API，确认服务器仍保留可按编号读取的旧对象。普通推送和本地清理无法删除这项缓存，需要联系 GitHub Support；官方是否受理由 GitHub 判断。公开报告不附旧提交编号或邮箱，具体清理信息仅留本地。现有公开分支和旧版本标签不需要重新改写。
- 本地检查 142 张历史及当前图片的可见文字，未命中已知真实账号、会话凭据或本机用户路径；未发现 EXIF/GPS 元数据。公开预览使用合成数据，真实运行窗口截图不进入发布目录。
- 从 GitHub 下载既有 v0.2.0、v0.3.1、v0.4.0 安装包，检查明文资源和压缩 Python 模块；对待发布 0.5.0 安装包做相同检查。未命中已知真实账号、会话凭据或本机用户目录。
- 额外提取 0.5.0 安装包内 934 个 Python 模块/启动脚本的字符串常量，Gitleaks 扫描未发现秘密。
- 第三方原生库中存在上游构建环境路径；已确认不包含本机用户目录，未通过修改依赖二进制来删除上游调试信息。

## 发布边界

原始设计参考图仅留本地，已加入忽略规则。数据库、Cookie/会话、二维码、真实媒体、审计过程材料、原始安装位置清单和私有 Git 备份均不进入 Git 提交。打包脚本生成的本机 `.spec` 文件继续保持忽略。

公开源码包含可编辑图标源文件、合成截图及复现工具；安装包单独作为 GitHub Release 附件发布，不写入 Git 历史。发布时只推送主分支与指定版本标签，不推送本机工具内部引用。

这些检查覆盖已知身份值、常见秘密模式和本次可见材料，不能证明不存在任何未知敏感信息。真实导出仍应保存在用户自己的设备上。

GitHub 官方说明：[Removing sensitive data from a repository](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)。历史改写后，旧提交仍可能通过编号或缓存访问；服务端清理需要 GitHub Support 协助。
