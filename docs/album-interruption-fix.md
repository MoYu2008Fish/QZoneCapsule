# 0.2.1 相册读取中断修复（2026-10-25）

## 复现与原因

对包含空相册和非空相册的样本进行只读验证，空相册正常；非空相册的照片接口返回 HTTP 200，但 JSON 内含未转义控制字符及损坏的字符串转义。标准 `json.loads` 先报 `Invalid control character`，放宽控制字符后仍报 `Expecting ',' delimiter`，因此原任务中断。这不是本次实测中的登录过期或 HTTP 500。

## 修复

- 接受字符串内的控制字符；对相册、照片端点的完整对象响应，使用本地 json-repair 恢复损坏字符串。
- 恢复结果须含业务状态、数据对象与相册或照片列表；继续检查业务错误。HTML、缺少结尾的响应和不符合结构的结果仍失败，不将其视为空相册。不执行响应中的 JavaScript。
- 单个相册照片读取失败，保留已获取记录，记录 `album_photos` 问题，并继续其他相册和说说；结果为 `partial`。取消仍为 `cancelled`。
- 读取相册选择列表时，将取消事件传入 HTTP 客户端。
