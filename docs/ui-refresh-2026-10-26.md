# 扣扣时光 UI 整理 · 2026-10-26

沿用 QQ 空间的深蓝页头、蓝色封面、白色动态卡片和浅灰蓝背景，以更克制的圆角、边框和排版整理层级。保留「扣扣时光」品牌，不引入网络字体、网络图片或第三方表情素材。

## 本轮改动

- `theme.py` 统一颜色、圆角、字级、字重、间距、阴影和 160 ms 动效令牌。Qt 控件、动态绘制和离线 HTML 共用颜色体系；原生控件即时反馈，HTML 动效遵从减少动态效果设置。
- 主窗口：深蓝顶部品牌栏替代大侧栏；圆形步骤编号、白色流程卡片、明确的按钮主次、禁用/悬停/焦点状态；任务进度与结果独立成卡，操作栏固定在底部。窗口最小宽度降至 680，正文可纵向滚动。
- 动态流：账号与时间分层、系统 Emoji、正文行距、圆角九宫格、点赞评论分隔区、悬停与键盘焦点边框。单条动态首屏最多展示九张，更多图片仍可从详情和查看器访问；列表不截断记录。
- 相册与照片：自适应网格、封面裁切、标题和来源；查看器使用统一白色舞台，保留上一张/下一张、方向键与关闭，窗口缩放时重新适配图片。
- 时光馆：四张账号范围统计卡、两行筛选区、短账号选项、独立结果数量与「查看全部」、明确的无结果提示、统一内容/失败/暂不支持弹窗和细滚动条。
- 保留按需解码与 96 张缩略图缓存，增加最多 256 份正文排版缓存，批量替换筛选结果期间暂停重绘。
- 离线 HTML 同步品牌栏、封面、卡片、三列图片、来源与时间层级、焦点样式和减少动态效果支持。已有导出页需重新生成后才能采用新视觉。
