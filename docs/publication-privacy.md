# 公开发布脱敏检查

本仓库只发布应用源码、合成测试样例、未登录演示截图及经过独立检查的安装包。

- 个人空间账号、Cookie、二维码、会话、媒体签名地址、说说原文、图片及完整存档不进入源码。
- 公开验证记录不包含个人存档条目统计和本机目录。测试账号与测试文字均为合成数据。
- Git 提交使用公开项目署名与 GitHub noreply 邮箱；不使用个人邮箱或本机主机名。
- `.gitignore` 排除数据库、导出页数据、日志、原始备份、会话与构建缓存。
- 发布前检查暂存的源码文件，执行秘密扫描，并检查图片内容与文件元数据。
- 安装包单独检查明文资源和压缩 Python 模块中的字符串、路径；源码检查不能代替安装包检查。

这些检查用于减少误上传风险。使用者自行导出的数据库、HTML、媒体和诊断文件仍可能包含其个人数据，应留在本地，反馈问题前另行脱敏。
